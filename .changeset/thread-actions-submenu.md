Group thread menu actions, rename Move to stage to Set stage, and edit prompt buttons in a compact submenu that saves as you type. Empty labels use the prompt as the button label. Rounded rows use placeholders for labels and prompts, with a trailing blank row for new actions and X to clear or remove a row. Prompts expand for editing and keyboard focus follows row navigation. Remove the Hide thread title option from the sidebar and CLI.
