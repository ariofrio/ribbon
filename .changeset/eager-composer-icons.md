Draw the project icon everywhere bb names a project, not only on sidebar
headers and above an open thread. That adds the prompt box's project control
and the menu it opens, the project rows in the `@` list, a project mentioned in
a prompt, the strip under an open thread, and the crumb above a project's own
settings.

Where bb draws its own folder the icon replaces it, matching that surface's
size and colour. Two projects sharing a name keep bb's folder, since their rows
give no way to tell them apart.

A new "Show around the prompt box" setting turns the new places off on their
own, and the thread-header setting now covers a project's own header too.
