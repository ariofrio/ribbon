"bb-plugin-breadcrumbs": minor
---

Mirror breadcrumbs around the composer. Existing threads no longer repeat the
project below the composer, while New thread moves its project selector into a
`Section > Project > New thread` header with a new section picker. The layout
is enabled by default and can be disabled in the plugin settings. The picker
tracks section changes made by other New thread controls. Fork drafts show the
section inherited from the fork source as read-only until changing projects
leaves fork mode.
